All field agents under the Tengu Newspaper Guild must follow this protocol to deploy the Bunbunmaru wire tap:

Ensure the local neural inference engine is active:
```bash
ollama --version
pip install ollama
```

### 2. Inscribe the Bunbunmaru Persona
Forge the unhinged reporter model directly from the Tengu [`Modelfile`](Modelfile):
```bash
# Acquire base optical vision weights
ollama pull qwen3.5:4b

# Stamp the Bunbunmaru persona onto the model
ollama create bunbunmaru -f Modelfile
```

### 3. Print the Scoop!
Hand photographic evidence to Aya and let the Tengu press blow it completely out of proportion:
```bash
# Analyze any image
python3 bunbunmaru.py path/to/your/evidence.jpg
```

This single command triggers the full pipeline:
1. 🪶 Interrogates the image using `bunbunmaru` in Ollama.
2. 📖 Grounds character reactions and commercial sponsors using [`data/gensokyo_directory.json`](data/gensokyo_directory.json).
3. 📢 Emits structured tabloid JSON with custom ads and eyewitness quotes.
4. 🖨️ Automatically invokes [`pressing/press.py`](pressing/press.py) to print:
   - `bunbunmaru_newspaper.html` (interactive web broadsheet)
   - `assets/bunbunmaru_newspaper.png` (high-res broadsheet clipping)

Or run the printing press standalone with any image:
```bash
python3 pressing/press.py path/to/your/evidence.jpg
```

Or re-harvest the latest Touhou lore from Touhou Wiki anytime:
```bash
python3 scrapping/scraper.py
```
